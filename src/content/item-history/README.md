# Item history capture

- `readHistoryVisit` reuses Quick Info parsing and the shared history normalizer; only complete, valid item ID/name/path metadata is captured. Template IDs never substitute for item IDs.
- `resolveHistoryScope` uses the existing Sitecore identity resolver and shared scope normalizer. Origin and database participate; language does not. The identity resolver retains its existing query-parameter precedence over the database input.
- `observeQuickInfo` delivers an initial callback and debounces relevant changes by 100 ms. It observes `#Editors` (or the header parent), filtering out unrelated field changes, with a separate value-attribute observation for a database input outside that subtree. Input/change events also cover property-based value updates.
- While capture is active, `ITEM_HISTORY_CAPTURE.ATTACHMENT_CHECK_MS` checks only editor-target and database-input identities every 1000 ms, including before initial attachment and during postback gaps. Identity changes disconnect and rebind the single observer and schedule capture; unchanged attachments do not trigger capture. There is no broad document-subtree observer. Explicit cleanup and pagehide remove observers, listeners, and timers.
- `startItemHistoryManager` is idempotent per Document. It deduplicates normalized scope plus all visit metadata, including name/path changes; incomplete postback states leave the last valid snapshot untouched. Failed writes are logged and allow the same snapshot to retry on a later relevant change.
- Capture runs in normal runtime independently of LBolt activity and toolbar visibility, never in worker runtime. No UI/navigation or per-tab storage writes are included: visits use `requestHistoryChange`; UI readers should use the existing shared `getHistory`/`subscribeHistory` APIs.
- Agents: Each changed valid visit also schedules structural discovery without awaiting it or the history writer. Deferred discovery is skipped after cleanup or an origin/database switch; discovery failures do not prevent history writes.
