# Privacy Policy

## Summary

Fobles for Sitecore is a browser extension designed to improve productivity in Sitecore environments. It does not collect, transmit, or sell personal information.

## What the extension accesses

The extension requests browser permissions for:

- storage: to store local preferences and extension state in the browser
- tabs: to detect the active Sitecore tab and support basic extension actions
- host access for http/https pages: so the extension can run on Sitecore pages you open in the browser

## What the extension does not do

- It does not collect user names, email addresses, or account data.
- It does not track browsing history outside the Sitecore pages you explicitly open.
- It does not send data to a remote server for analytics or telemetry.
- It does not sell or share data with third parties.

## Local-only behavior

Preferences and state are stored locally in the browser using Chrome/Edge extension storage APIs. Any data stored is limited to extension preferences needed for features like menu state, AI Pages mappings, and toolbar positioning.

## Changes to this policy

This policy may be updated from time to time as the extension evolves. The current version is the one published in this repository.

## Contact

For privacy or support questions, use the support URL for the extension listing or file an issue in the project repository.
